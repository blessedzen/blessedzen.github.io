NBA Stat Checker — Updated project

Files:
- index.html: page structure and links to CSS and JavaScript
- style.css: website styling
- script.js: interactive features and ESPN data requests

New localStorage feature:
Save favorite NBA teams from a team profile. Favorites appear in "My favorite teams" and remain saved in this browser after refreshing or closing it. Use Remove to delete a favorite.

To run:
Keep all files in the same folder. Open index.html in a browser, or publish the folder with GitHub Pages.

The site uses ESPN's public, unofficial data endpoints. Their availability and response format can change.
